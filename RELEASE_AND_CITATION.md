# GitHub release and citation

The repository itself can be cited directly from the manuscript.

Recommended workflow:

1. Keep the repository public.
2. Confirm that `COLAB_REPRODUCE.ipynb` runs from a clean Colab session.
3. Before submitting the manuscript, create a tagged GitHub release such as `v1.0.0` so the version associated with the submission is identifiable.
4. Keep the development repository at `https://github.com/Enso-bio/quantum-otto-leakage`.

Suggested manuscript wording:

> The Python source code, numerical data, validation scripts, and figure-generation routines required to reproduce the principal results of this study are publicly available at GitHub: https://github.com/Enso-bio/quantum-otto-leakage.
